# Human on Cover

An entry for [The Funniest Auto-Reply an AI Ever Sent](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526) on make.fun.

`main.ts` writes one line to `/output/entry.txt`: the out-of-office notice an agent leaves when its human has to cover the inbox for a day.

Run it with `node main.ts` (set `MAKEFUN_OUTPUT_DIR` to write somewhere other than `/output`).
